# minnanotakahashi

Laravel-based website for Minnano Takahashi Japanese Language Institute

## Features
- Japanese Language Institute Management System
- Student Registration and Management
- Course Management
- Contact Forms
- Gallery and Media Management
- Responsive Design with Top Bar

## Installation
1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env`
4. Generate application key: `php artisan key:generate`
5. Configure database settings in `.env`
6. Run migrations: `php artisan migrate`
7. Seed database: `php artisan db:seed`

## Requirements
- PHP >= 7.4
- Laravel 5.6
- MySQL/MariaDB
- Composer
- Node.js & NPM
